# Product Analytics Dashboard

Product Analytics Dashboard is a static product metrics workspace for growth, activation, conversion, retention, and event review.

## MVP

- KPI cards
- Segment and date-range controls
- Activation trend chart
- Conversion funnel
- Recent events table
- Responsive dashboard layout

## Tech

- HTML
- CSS
- JavaScript
- Inline SVG
- GitHub Pages

## Why This Exists

This project shows dashboard information architecture and product metric judgment without requiring a backend analytics pipeline.
