# 徐铭杰 · 综合作品集

个人视觉作品、内容实践、调研协作与可运行技术案例。静态 HTML / CSS / JavaScript，无构建依赖。

## 本地预览

在此目录运行 `python -m http.server 4317 --bind 127.0.0.1`，浏览器打开 http://127.0.0.1:4317/ 。对账案例使用 ES modules 和 fetch，请通过 HTTP 预览。

## 真实项目入口

- Sheet Butler 浏览器案例：`data/`。基于本人公开仓库 https://github.com/MmIiNnGgXx/sheet-butler 的模拟案例与 CSV 解析器制作，新增浏览器对账与界面。
- 小步镇：https://mmiinnggxx.github.io/tiny-step-town/ 。已有公开 PWA，本次作品集接入并核验目标与首次行动创建，保留原仓库 https://github.com/MmIiNnGgXx/tiny-step-town 。

## 对账结果与复现

数据为原项目生成器创建的模拟订单，不是客户数据。500 条订单与 496 条台账，10 条仅左表有、6 条仅右表有、15 条字段不一致、475 条一致。原 Node 对账程序与浏览器实现均核对预埋答案。这里不宣称商业效果。

运行 `node data/core.test.mjs` 检查案例结果、金额等价、重复键、CSV 格式、非法金额与导出公式前缀防护。网页支持上传 CSV、自动分隔符识别、UTF-8 / GBK 解码、共同键选择、差异筛选、订单搜索、分页与 CSV 导出。金额字段按分比较；文件上限 5 MB，记录上限 10,000 行，重复或空白键会拒绝。其他共同字段按去首尾空格后的字符串比较。在线版不支持 XLSX；完整 Node 原项目支持。

数据只在浏览器处理，不上传服务器。计算结果仍需结合原始凭证人工核对，不替代财务审计。
