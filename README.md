# 徐铭杰 Personal Website

Public portfolio hub for job hunting and product-level project demos.

Live source: <https://github.com/MmIiNnGgXx/personal-website>

## Purpose

This site presents a focused portfolio matrix instead of a generic resume page. It is designed to link several small but complete product projects:

- AI Resume Reviewer
- Job Search Dashboard
- Product Analytics Dashboard
- Commerce CMS Dashboard
- Habit Focus Tracker

## Current MVP

- Static GitHub Pages-friendly homepage
- Product positioning
- Project matrix
- Build plan
- GitHub source link
- Responsive layout without frontend dependencies
