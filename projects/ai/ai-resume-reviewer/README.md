# 简历与岗位诊断

中文优先的可交互前端作品，英文仅作辅助标题。

[在线体验](https://mmiinnggxx.github.io/personal-website/ai-resume-reviewer/)

## 已实现

关键词匹配分、能力缺口、项目表达模板、最近五次分析摘要、Markdown 导出。

## 技术与运行

HTML、CSS、原生 JavaScript。直接打开 index.html，或通过 GitHub Pages 访问。无安装与构建步骤。

## 当前边界

本地关键词规则，未接入大模型；分数仅表示关键词覆盖，不预测录用概率。目标岗位用于报告表达，匹配计算依据输入的岗位要求。
